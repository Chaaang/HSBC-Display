# Signature Display App

A companion display application for the [Digital Signature Board](https://github.com/yourusername/digital-signature-board), designed to showcase signatures captured from the signing application in real time.

The application receives and displays all submitted signatures on a large screen, creating an interactive and visual signature wall for events and customer experiences.
